# دليل البدء السريع (Quickstart) — LocalPilot 🚀

هذا الدليل مخصص للمستخدمين غير التقنيين والباحثين والمطورين الذين يرغبون في تشغيل الذكاء الاصطناعي محلياً على حواسيبهم في خطوات عملية ومبسطة.

---

## الخطوة 1: التثبيت (Installation)

### الخيار الأفضل (سطر أوامر واحد بدون إعدادات يدوية):
افتح نافذة الطرفية (Terminal) في نظامك:
- **في ماك (macOS):** اضغط `Command + Space` واكتب `Terminal` ثم اضغط `Enter`.
- **في لينكس (Linux):** اضغط `Ctrl + Alt + T`.

ثم انسخ والصق الأمر التالي:

```bash
curl -fsSL https://raw.githubusercontent.com/fakhruldeen/LocalPilot/main/install-localpilot.sh | bash
```

> **ملاحظة أمان:** هذا السكريبت لا يطلب كلمة مرور المسؤول (`sudo`) ويعمل بالكامل داخل مساحة المستخدم المعزولة الخاصة بك (`~/.local/share/localpilot`).

---

## الخطوة 2: فحص توافق الحاسوب (`doctor`)

تأكد من أن عتاد جهازك وموارده جاهزة عبر الأمر التشخيصي:

```bash
localpilot doctor
```

سيقوم الأمر بفحص:
1. المعالج (CPU) وعدد الأنوية المتاحة.
2. سعة الذاكرة العشوائية الحقيقية (RAM) والمساحة الآمنة المتبقية.
3. معالجات الرسوميات وتسريع العتاد (Apple Silicon Metal على الماك، أو NVIDIA CUDA على لينكس).
4. مساحة التخزين المتاحة.

---

## الخطوة 3: استعراض النماذج المتوافقة (`discover`)

شاهد النماذج التي تناسب مواصفات جهازك فقط، دون إرهاق الذاكرة:

```bash
# استعراض كافة النماذج المتوافقة مع جهازك
localpilot discover

# تصفية النماذج المتخصصة في المحادثة والكتابة
localpilot discover --task chat

# البحث عن عائلة محددة (مثل نماذج Llama)
localpilot discover -q "llama"
```

---

## الخطوة 4: تحميل وتثبيت أول نموذج (`setup`)

اختر أحد النماذج الموصى بها (مثلاً `llama3.2:3b` الخفيف والسريع):

```bash
localpilot setup llama3.2:3b
```

ماذا يحدث في هذه الخطوة؟
- يتم تنزيل ملف أوزان النموذج الأصلي مع إظهار شريط التقدم الحقيقي.
- يتم التحقق من البصمة الرقمية والتشفير (SHA-256).
- يتم اختبار توليد نص تجريبي (Smoke Inference) للتحقق الفعلي من عمل النموذج قبل تسجيله كجاهز للاستخدام.

---

## الخطوة 5: بدء المحادثة الفورية (`chat` أو `tui`)

يمكنك بدء المحادثة مباشرة عبر سطر الأوامر:

```bash
localpilot chat llama3.2:3b
```

أو تشغيل لوحة التحكم الرسومية التفاعلية الكاملة:

```bash
localpilot tui
```

### أوامر مفيدة أثناء المحادثة:
- `/help` — عرض المساعدة والتعليمات.
- `/exit` أو الضغط على `Ctrl + C` — الخروج الآمن وإلغاء تحميل النموذج من الذاكرة العشوائية فوراً لإعادتها لنظام التشغيل.

---

## الخطوة 6: إدارة المساحة التخزينية وحذف النماذج

يمكنك مراجعة المساحة المستهلكة أو استرجاعها في أي وقت:

```bash
# عرض تقرير استهلاك القرص الصلب
localpilot storage

# حذف نموذج بأمان وتحرير مساحته
localpilot remove llama3.2:3b --delete-files
```

---

## الخطوة 7: التحديث أو إلغاء التثبيت النظيف

```bash
# فحص وتحديث تطبيق LocalPilot من مستودع PyPI
localpilot self update

# إلغاء تثبيت التطبيق بالكامل وحذف النماذج المخزنة بنقرة واحدة
localpilot self uninstall --purge-models
```
