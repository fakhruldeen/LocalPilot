تثبيت سريع، آمن، ومعزول

خيارات التثبيت وإدارة النظام

سواء كنت مبتدئاً تبحث عن أمر تثبيت بنقرة واحدة، أو مطوراً يفضل أدوات Python وبيئات العمل المعزولة، ستجد هنا الطريقة المثالية لجهازك.

الطريقة الأولى (موصى بها للمبتدئين)

المثبت التلقائي عبر الطرفية

الأسهل والآمن

يقوم السكربت بفحص نظامك، إعداد بيئة بايثون افتراضية معزولة تلقائياً في مجلد المستخدم، تثبيت أحدث إصدار من LocalPilot، وربط الأمر مباشرة دون التأثير على أي إعدادات أخرى في نظامك.

curl -fsSL https://raw.githubusercontent.com/fakhruldeen/LocalPilot/main/install-localpilot.sh | bash
✓ يعمل بسلاسة على نظام macOS (معالجات Apple Silicon و Intel) وتوزيعات Linux (Ubuntu, Debian, Fedora, Arch).
الطريقة الثانية (لمستخدمي بايثون)

التثبيت عبر pipx أو pip أو uv

⚠️
المتطلبات المسبقة لهذه الطريقة: تتطلب هذه الطرق وجود Python (الإصدار 3.11 أو أحدث) ومدير الحزم pip مثبتاً بالفعل على حاسوبك. إذا لم تكن بايثون مثبتة لديك، استخدم الطريقة الأولى أعلاه.

1. عبر pipx (موصى بها لأدوات CLI):

تعزل الحزمة تلقائياً وتتيح لك تشغيل أمر localpilot عالمياً من أي مكان:

pipx install localpilot

2. عبر pip القياسي أو uv:

pip install -U localpilot
# أو عبر أداة uv السريعة:
uv tool install localpilot
إعدادات النطاق المتقدمة

نطاقات تثبيت المحركات والنماذج (Installation Scopes)

عند تثبيت محركات التشغيل المساندة، يتيح لك LocalPilot اختيار مستوى العزل المناسب:

Isolated (الافتراضي)

نطاق معزول تماماً

يتم تثبيت المحركات داخل مجلد LocalPilot الخاص فقط. لا يتطلب صلاحيات root، ولا يؤثر على أي بيئات برمجية أخرى في جهازك.

User Space

نطاق مستخدم النظام

تثبيت في المجلد العام للمستخدم (~/.local/bin)، مفيد لمشاركة المحركات مع أدوات أخرى يدوياً.

System Scope

نطاق كامل النظام

تثبيت عام في مسارات النظام المشتركة (/usr/local/bin). يتطلب صلاحيات المسؤول (sudo).

🔄 كيفية التحديث والترقية

للتحقق من وجود إصدارات جديدة لـ LocalPilot من مستودع PyPI وترقيتها فوراً:

localpilot self update

لتحديث أوزان نموذج مثبت مسبقاً في حال أصدر مؤلفه نسخة محسنة:

localpilot update <installation-id>

🗑️ إلغاء التثبيت النظيف

إلغاء تثبيت شفاف بالكامل دون ترك أي ملفات مخفية:

# إزالة التطبيق مع الاحتفاظ بملفات النماذج:
localpilot self uninstall

# أو إزالة تامة تشمل حذف النماذج وقاعدة البيانات:
localpilot self uninstall --purge-models
