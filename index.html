$ pip install localpilot

Engineered for Simplicity & Safety

Everything needed to run open models on your local machine with confidence.

Hardware-Aware Fit

Accurate memory accounting for Apple Silicon unified memory vs. discrete Linux/Intel GPUs. Incompatible models are excluded before you download gigabytes of weights.

3-Axis Execution Plan

Decouples inference into Computation Engine (llama.cpp, vLLM), Managed Service (Ollama, LM Studio / llmster), and Deployment Method (direct_worker, local_service).

Zero Data Loss & Safe Removal

External background daemons are never killed automatically; models are unloaded from VRAM cleanly. Reference-counted storage ensures shared weights are protected.
