Questions & Answers

Frequently Asked Questions

No complex jargon, just straightforward answers.

Do I need an expensive gaming computer?

No! While huge models require specialized hardware, compact and powerful models (like 1.5B and 3B parameter models) run fast and smoothly on everyday laptops, including MacBook Airs and typical desktop PCs.

Do I need to know Docker or programming?

Not at all. LocalPilot runs directly on your machine without requiring Docker or developer knowledge. If you happen to already have tools like Ollama or LM Studio installed, LocalPilot quietly recognizes them and works alongside them.

Will this touch or mess up my personal files?

Never. LocalPilot isolates all model files and settings inside its own dedicated application directory. It will never modify your system packages, personal documents, or other Python projects.

How do I free up disk space when I'm done?

You can safely remove any installed model with a single command (localpilot remove <id>) or from the dashboard. It deletes the model file cleanly without leaving residual garbage.

The 3-Axis Architectural Model

LocalPilot replaces flat runtime models with three orthogonal execution dimensions:

Inference Backend llama.cpp, vLLM, mlx-lm
Managed Service Ollama, LM Studio / llmster, Docker Model Runner
Deployment Method direct_worker, local_api, container

LocalPilot inspects the system to discover existing services and backends, constructs an explicit ExecutionPlan, and tracks model execution without killing external background daemons or mutating host permissions.
