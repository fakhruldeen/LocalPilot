System Safety

Safety & Operational Principles

Designed to protect your hardware and keep your computer stable.

1

Safe Memory Budget

Calculates safe RAM allocation before download to leave room for your operating system and desktop apps.

2

Local Loopback Binding

Endpoints bind strictly to loopback address 127.0.0.1. No remote public ports or automatic cloud uploads.

3

No Root / Sudo Required

Runs in unprivileged user space. Never modifies system files or requires administrator elevation.

4

Respects External Services

Connects to existing Ollama or LM Studio daemons without killing shared background processes on model stop.

5

Preserves Models on Removal

Uninstallation keeps your downloaded model files by default, with an optional flag if you want to purge models.

★

Free & Open Source

Licensed under GNU GPLv3. Transparent public code and active community development.
