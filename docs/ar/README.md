## 💡 ما الذي يساعدك LocalPilot على إنجازه؟

يتيح لك LocalPilot تنزيل نماذج الذكاء الاصطناعي وتشغيلها مباشرة على جهازك المكتبي أو المحمول.

يمكنك استخدامه في:
* **صياغة وتحرير النصوص:** كتابة رسائل البريد الإلكتروني، إعداد ملخصات المقالات، تحسين أسلوب المستندات، وإعادة صياغة الأفكار.
* **الإجابة عن الأسئلة اليومية:** تلخيص المستندات الكبيرة، تبسيط وشرح المفاهيم المعقدة، والعصف الذهني.
* **المساعدة في البرمجة:** شرح الشيفرات البرمجية، المساعدة في كتابة الدوال، واستكشاف الأخطاء البرمجية.
* **إجراء محادثات داخل جهازك:** التحدث مع نموذجك عبر نافذة الطرفية، حيث تتم المعالجة بالكامل داخل جهازك دون إرسال محادثاتك إلى خوادم سحابية.

---

## 👥 لمن هذا البرنامج؟

* **المستخدمون غير التقنيين والمبتدئون:** لا تحتاج إلى خلفية هندسية أو خبرة مسبقة في الذكاء الاصطناعي. يتولى التطبيق حساب سعة الذاكرة وإعداد الإعدادات المناسبة لجهازك.
* **الباحثون والكتّاب المهتمون بالخصوصية:** إبقاء الملاحظات والمسودات والأعمال الحساسة على جهازك الخاص.
* **الطلاب والمبرمجون:** تجربة أحدث النماذج مفتوحة المصدر (مثل Llama وQwen وGemma وMistral) مع واجهة برمجية محلية جاهزة وموثوقة.

---

## 💻 ما هي متطلبات التشغيل؟

* **نظام التشغيل:** **لينكس (Linux)** بمختلف توزيعاته، أو **ماك (macOS)** بمعالجات Apple Silicon (M1 إلى M4) أو معالجات Intel. أما نظام **ويندوز (Windows)** فيعمل التطبيق عبر بيئة WSL2.
* **الطرفية (Terminal):** نافذة سطر أوامر قياسية لتشغيل التطبيق.
* **اتصال بالإنترنت:** تحتاجه فقط أثناء التثبيت الأولي، وتنزيل النموذج لأول مرة، وتحديث قائمة النماذج. (بعد التنزيل، تتم المحادثة محلياً دون الحاجة للإنترنت).
* **المواصفات والذاكرة:**
  * **8 جيجابايت من الذاكرة العشوائية (RAM)** و**10 جيجابايت مساحة تخزين خالية** للنماذج الخفيفة (1.5 إلى 3 مليارات معامل).
  * **16 جيجابايت أو أكثر من الذاكرة** للنماذج القياسية (7 إلى 8 مليارات معامل).
* **بايثون (Python):** يلزم توفر إصدار Python 3.11 أو أحدث (يتحقق مثبت النظام من وجوده تلقائياً).

## 🚀 ابدأ الاستخدام

### طريقة التثبيت الموصى بها (المثبت التلقائي)

افتح نافذة الطرفية (Terminal) وألصق هذا الأمر:

```bash
curl -fsSL https://raw.githubusercontent.com/fakhruldeen/LocalPilot/main/install-localpilot.sh | bash
```

**ما الذي يفعله هذا الأمر؟**
1. يفحص توافق نظام التشغيل وإصدار بايثون في جهازك.
2. يثبت البرنامج داخل مجلد تطبيق مستقل ومعزول (`~/.local/share/localpilot` على لينكس، و`~/Library/Application Support/LocalPilot` على ماك).
3. لا يمس ملفات نظامك ولا يطلب منك إدخال كلمة مرور مدير النظام (`sudo` أو root).

---

### طرق تثبيت بديلة (لمطوري بايثون)

إذا كنت تفضل إدارة أدوات بايثون عبر `pipx` أو `pip` أو `uv`:

```bash
# باستخدام pipx (الخيار الموصى به لمطوري بايثون)
pipx install localpilot

# باستخدام pip في بيئتك الحالية
pip install localpilot

# باستخدام uv
uv tool install localpilot
```

👉 *للحصول على خيارات التثبيت المتقدمة أو إرشادات إلغاء التثبيت، راجع **[دليل التثبيت](docs/ar/INSTALLATION.md)**.*

## 🖥️ ماذا يحدث بعد التشغيل؟

لتشغيل LocalPilot، اكتب الأمر التالي في الطرفية:

```bash
localpilot
```

ستفتح أمامك لوحة تفاعلية داخل الطرفية. إذا كانت هذه أول مرة تشغل فيها البرنامج، سيرشدك معالج التثبيت خلال الخطوات الآتية:

1. **فحص مواصفات الجهاز:** يقيس البرنامج قدرات المعالج والذاكرة وبطاقة الرسوميات، ويحجز هامشاً آمناً لضمان بقاء متصفحك ونظام التشغيل في حالة استقرار.
2. **اختيار الهدف المطلوب:** اختر ما تريد مساعدة الذكاء الاصطناعي فيه: *أسئلة يومية وكتابة*، أو *مساعدة برمجية*، أو *استعراض كافة النماذج المتوافقة*.
3. **النماذج المقترحة:** يعرض البرنامج قائمة بالنماذج التي يتوقع أن تناسب سعة الذاكرة في جهازك.
4. **المراجعة والموافقة:** يوضح لك التطبيق اسم النموذج وحجم التنزيل ومكان التخزين، ولا يبدأ التنزيل إلا بعد الضغط على **Set Up Model**.
5. **التنزيل والتحقق:** يقوم التطبيق بتنزيل الملف، وإعداد برنامج تشغيل النماذج المناسب، وإجراء سؤال تجريبي سريع للتحقق من جاهزية النموذج على جهازك.
6. **بدء المحادثة:** اختر **Start Chatting** للبدء فوراً في التحدث مع النموذج.

## 💬 الأوامر اليومية المعتادة

بعد تثبيت النموذج، يمكنك إدارة الذكاء الاصطناعي بسهولة عبر أوامر واضحة:

| المهمة | الأمر | النتيجة المتوقعة |
| :--- | :--- | :--- |
| **فتح اللوحة التفاعلية** | `localpilot` | يفتح لوحة التحكم الرسومية التفاعلية داخل نافذة الطرفية. |
| **بدء المحادثة** | `localpilot chat` | يفتح نافذة المحادثة مع نموذجك المثبت. اكتب `/exit` للمغادرة. |
| **إيقاف النموذج (تحرير الذاكرة)** | `localpilot stop` | يفرغ النموذج من الذاكرة لتعود كافة موارد RAM وبطاقة الرسوميات لتطبيقاتك الأخرى. |
| **فحص مواصفات الجهاز** | `localpilot doctor` | يحلل المعالج والذاكرة المتاحة وبطاقات الرسوميات المكتشفة. |
| **عرض النماذج المثبتة** | `localpilot installed` | يعرض قائمة النماذج المحفوظة حالياً على قرصك الصلب. |
| **استكشاف نماذج متوافقة** | `localpilot discover` | يفحص كتالوج النماذج ويعرض المتوافق منها مع ميزانية ذاكرتك. |
| **حذف نموذج** | `localpilot remove <name>` | يحذف ملفات النموذج من قرصك الصلب لتوفير المساحة. |
| **إضافة نموذج للمفضلة** | `localpilot favorite add <alias>` | يضيف الاسم المختصر للنموذج إلى قائمة مفضلاتك للوصول السريع. |

> [!TIP]
> **الفرق بين مغادرة المحادثة وإيقاف النموذج:**
> * كتابة `/exit` تُغلق جلسة الدردشة فقط لكنها تُبقي النموذج في الذاكرة لتتمكن من العودة إليه فوراً دون انتظار إعادة تحميله.
> * أمر `localpilot stop` يوقف النموذج بالكامل ويفرغه من الذاكرة، مما يعيد الذاكرة العشوائية لجهازك فوراً.

## 🔒 الخصوصية والاتصال بالإنترنت والحدود الفنية

* **معالجة محلية:** تجري المحادثات المدعومة محلياً عبر اتصال داخلي مغلق (`127.0.0.1`). لا تُرفع أسئلتك أو ملفاتك إلى خوادم سحابية.
* **متطلبات الإنترنت:** يلزم الاتصال بالإنترنت أثناء التثبيت، وتنزيل النموذج لأول مرة، وتحديث قائمة النماذج. بعد اكتمال التنزيل، تعمل المحادثة دون الحاجة لشبكة الإنترنت.
* **تنبيه حول الدقة:** مثل سائر نظم الذكاء الاصطناعي، قد تُنتج النماذج معلومات غير دقيقة أو أخطاء في الشيفرات البرمجية. احرص دائماً على مراجعة الإجابات قبل الاعتماد عليها في أعمال هامة.
* **حدود قدرات الجهاز:** تتشارك النماذج المحلية الذاكرة مع بقية برامجك. قد يؤدي اختيار نماذج تفوق سعة جهازك إلى بطء في الأداء؛ لذلك يحدد LocalPilot ميزانية آمنة للذاكرة لتجنب هذا الإجهاد.

## 🔌 خيار إضافي: ربط التطبيقات والمحررات البرمجية

يوفر LocalPilot واجهة برمجية محلية متوافقة مع نمط OpenAI القياسي عبر العنوان (`http://127.0.0.1:8080/v1`).

يمكنك ربط المحررات البرمجية الشائعة:
* **محرر VS Code (إضافة Continue):** لإجراء المحادثات البرمجية مباشرة مع ملفات مشروعك.
* **أداة OpenCode:** توليد آلي لإعدادات التطبيق لربطه بالنموذج المحلي.
* **محرر Cursor والتطبيقات المخصصة:** توجيه أي تطبيق يدعم OpenAI إلى العنوان المحلي لجهازك.

اكتب `localpilot connect` لعرض خطوات الربط لكل تطبيق.  
*(تنبيه: تخضع التطبيقات الخارجية لسياسات الخصوصية والإعدادات الخاصة بمطوريها).*

## 🛠️ المساعدة واستكشاف الأخطاء الشائعة

* **انقطاع التنزيل:** أعد تشغيل أمر `localpilot`، وسيقوم المثبت بالتحقق من الأجزاء المحملة واستئناف التنزيل بأمان.
* **بطء الحاسوب أو امتلاء الذاكرة:** اكتب `localpilot stop` لإفراغ النموذج من الذاكرة، أو اختر نموذجاً أخف عبر `localpilot discover`.
* **الأمر غير موجود (`localpilot: command not found`):** تأكد من إضافة مسار البرامج المحلية إلى الطرفية بإضافة السطر التالي في ملف `~/.bashrc` أو `~/.zshrc`:  
  `export PATH="$PATH:$HOME/.local/bin"`
* **طلب مفتاح وصول (Access Key):** أغلب النماذج مفتوحة ومتاحة دون حسابات، إلا أن بعض النماذج المقيدة (مثل نسخ Llama أو Gemma على Hugging Face) تشترط الحصول على مفتاح وصول شخصي مجاني (Read-only Token) لتأكيد موافقتك على شروط الناشر.
* **طلب تقرير تشخيصي:** نفذ أمر `localpilot support` لإنشاء تقرير تشخيصي نظيف وخالٍ من البيانات الحساسة يمكنك مراجعته ومشاركته عند طلب الدعم.
