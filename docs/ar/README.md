## 🌟 المبادئ الجوهرية لـ LocalPilot

1. **الخصوصية المطلقة (100% محلي):** لا يتم إرسال محادثاتك أو نصوصك أو ملفاتك إلى أي خادم خارجي عبر الإنترنت. يعمل بالكامل في وضع الطيران (Offline).
2. **حماية موارد الحاسوب:** لا يسمح بتحميل أي نموذج يتجاوز السعة الآمنة للذاكرة العشوائية (RAM)، لحماية نظامك من التجمد أو البطء.
3. **احترام البرمجيات المثبتة مسبقاً:** إذا كان لديك Ollama أو LM Studio مثبتاً بالفعل، فإن LocalPilot يتعرف عليه ويتكامل معه بسلام، ولا يقوم بحذف ملفاته أو إيقاف خدماته إطلاقاً.
4. **صفر تكلفة وسهولة تامة:** مجاني ومفتوح المصدر بالكامل (GPLv3)، لا اشتراكات شهرية، ولا مفاتيح برمجية (API Keys).

## 🤝 المساهمة في التوثيق العربي
نرحب بمساهمات المطورين والمترجمين في إثراء المحتوى العربي، ومراجعة المصطلحات التقنية، وتحديث الأدلة بما يتوافق مع الإصدارات الجديدة للمشروع.
