المعمارية التقنية ودليل سطر الأوامر

استعراض هندسي دقيق لمعمارية المحاور الثلاثة، خوارزميات قياس واحتساب الذاكرة، سياسات إدارة العمليات، والمرجع الكامل لأوامر CLI.

الهندسة البرمجية والنطاق

المعمارية السداسية النظيفة (المنافذ والمحولات - Hexagonal Architecture)

تمت هندسة LocalPilot بالاعتماد على نموذج التصميم المقاد بالنطاق (Domain-Driven Design) مع حدود سداسية صارمة تفصل بين منطق العمليات الأساسي وقواعد التحقق وبين أدوات واجهة المستخدم أو محركات التشغيل الخارجية، بحيث تعمل النواة بنسبة 100% دون أي تبعيات خارجية أو مكتبات TUI أو أدوات تشغيل ثانوية.

1. طبقة العرض والواجهات (Presentation Layer)
منافذ واجهة المستخدم (Inbound Ports)
Typer CLI توجيه الأوامر، جداول Rich التفاعلية، ومخرجات JSON والنصوص البسيطة للأتمتة
localpilot
Textual TUI Hub لوحة تحكم رسومية كاملة داخل الطرفية، تدفق فوري للسجلات، ومودال المساعدة F1
localpilot tui
▼ استدعاء حالات الاستخدام عبر حدود تنفيذ منضبطة ومعزولة
2. طبقة التطبيق والتنسيق (Application Layer)
سير العمليات والمعاملات (Workflows)
SetupWorkflow تنزيل ← تشغيل ← فحص
RuntimeService دورة الحياة والمنافذ
UpdateWorkflow تحديث ذري مع التراجع
JobManager المهام في الخلفية
ActivityService سجل العمليات المنقح
▼ فرض قواعد وسياسات النطاق الحسابية وخوارزميات التقييم
3. نواة النطاق الأساسية (Domain Core - خالية من التبعيات)
منطق بايثون النقي
CompatibilityPolicy

احتساب تفريغ الذاكرة للـ GPU والـ RAM مع حجز مساحة أمان 512MB للنظام.

ScoringPolicy

أوزان ترجيح متعددة العوامل: التوافق، السرعة، جودة التكميم، والتسريع العتادي.

ExecutionPlan

ثلاثية التنفيذ غير القابلة للتغيير: (المحرك الحسابي × نوع الخدمة × نمط النشر).

VerifiedState

آلة حالات صارمة تعتمد الإثبات الفعلي: UNTESTED ← DOWNLOADED ← TESTED_HERE.

▼ قيادة البنية التحتية والعتاد عبر واجهات التوصيل والمحولات (SPI) ▼

الهندسة البرمجية

معمارية المحاور الثلاثة للتنفيذ (3-Axis Architecture)

يقوم LocalPilot بفصل عملية تشغيل نماذج اللغة إلى ثلاثة محاور متعامدة ومستقلة تماماً:

المحور الأول: المحرك (Backend)

محركات الاستدلال الحسابي

المحرك البرمجي المسؤول عن ضرب المصفوفات وتوليد الرموز:

  • • llama.cpp (GGUF, Metal, CUDA)
  • • vLLM (أنظمة GPU المتقدمة)
المحور الثاني: الخدمة (Service)

خدمات الإدارة والتنسيق

الطبقة المسؤولة عن دورة حياة النماذج وإدارة الموارد:

  • • Direct / Embedded (مباشر)
  • • Ollama Daemon
  • • LM Studio / llmster
المحور الثالث: النشر (Deployment)

أسلوب وطريقة التشغيل

كيفية استدعاء العملية والتواصل معها داخل النظام:

  • • direct_worker (عملية فرعية معزولة)
  • • local_api_service (خادم محلي)
  • • container (حاوية معزولة)
الحسابات الرياضية

خوارزمية ميزانية الذاكرة الآمنة (Memory Budget Math)

لتجنب تجميد نظام التشغيل أو انهيار العمليات، يطبق LocalPilot معادلات ميزانية دقيقة تختلف بحسب معمارية العتاد:

1. أجهزة Apple Silicon (macOS):

في الذاكرة الموحدة (Unified Memory)، يتم حجز ميزانية آمنة لا تتجاوز:

Safe_RAM = min(Available_RAM * 0.85, Total_RAM * 0.70)

هذا يضمن بقاء مساحة كافية لتطبيقات النظام وواجهة المستخدم الرسومية.

2. حواسيب Linux وبطاقات NVIDIA:

حساب دقيق لطبقات كارت الشاشة (GPU Offload Layers):

VRAM_Budget = Available_VRAM * 0.90
KV_Cache = 2 * layers * heads * dim * context * bytes

إذا لم تتسع VRAM بالكامل، يتم تفعيل التشغيل الهجين (Partial Offload) بين كرت الشاشة والرام.

المرجع الشامل

دليل أوامر سطر الأوامر (CLI Reference)

جميع الأوامر تدعم الخيارات --plain للأتمتة النصية و --json للمخرجات المهيكلة:

الأمر الوصف الموجز مثال على الاستخدام
localpilot doctor فحص العتاد، سعة الذاكرة، كروت الشاشة، ومحركات التشغيل المتوفرة. localpilot doctor --json
localpilot discover استعراض النماذج المتوافقة مع مواصفات جهازك وميزانية الذاكرة وتقييم أدائها. localpilot discover -q "qwen"
localpilot setup <ID> تنزيل النموذج، فحص البصمة، وإجراء فحص استدلال حقيقي قبل الاعتماد. localpilot setup cand_llama32_3b
localpilot run <ID> بدء تشغيل النموذج المحمل وجعله جاهزاً للمحادثة واستقبال الطلبات. localpilot run inst_llama32_3b
localpilot chat <ID> بدء محادثة فورية وتدفق الكلمات مباشرة في الطرفية بشكل خاص. localpilot chat inst_llama32_3b
localpilot stop <ID> إيقاف النموذج وتفريغ الذاكرة فوراً وإعادتها لنظام التشغيل. localpilot stop inst_llama32_3b
localpilot installed عرض مكتبة النماذج المثبتة على حاسوبك وأحجامها وحالتها. localpilot installed
localpilot running عرض النماذج والعمليات النشطة قيد الاستخدام في الخلفية. localpilot running --json
localpilot docs استعراض المراجع الهندسية العميقة للمعمارية، تفريغ الذاكرة، والأمان في الطرفية. localpilot docs --topic technical
localpilot remove <ID> حذف ملفات النموذج المحملة واحتساب المراجع وتحرير مساحة القرص الصلب فوراً. localpilot remove llama3.2:3b -y
localpilot logs استعراض سجلات التشغيل مع حجب المفاتيح السرية والمسارات الشخصية تلقائياً. localpilot logs --lines 50
localpilot activity سجل زمني لعمليات التثبيت، التشغيل، والإيقاف لتدقيق النشاط. localpilot activity --json
localpilot storage تفصيل استهلاك التخزين للملفات المؤقتة والأوزان وقاعدة البيانات. localpilot storage
localpilot guide استعراض التوثيق المدمج التفاعلي للمبتدئين والمطورين في الطرفية. localpilot guide novice
localpilot support توليد تقرير تشخيصي منقح بالكامل للمساعدة وحل المشكلات. localpilot support -o ./debug.json
localpilot self update فحص مستودع PyPI وترقية تطبيق LocalPilot لأحدث إصدار رسمي. localpilot self update
localpilot self uninstall إلغاء تثبيت التطبيق بنظافة، مع خيار حذف النماذج أو الاحتفاظ بها. localpilot self uninstall --purge-models
localpilot versions إدارة إصدارات النماذج الثابتة، وتثبيت الإصدارات المعتمدة (Pin) ضد الحذف التلقائي، والمقارنة جنباً إلى جنب، والحذف الآمن مع حماية الملفات المشتركة. localpilot versions list
localpilot alias إدارة الأسماء المستعارة الثابتة للتطبيقات (مثل default و coding) مع التبديل الذري بين الإصدارات والتراجع الفوري (Rollback). localpilot alias set coding ver-new
localpilot gateway تشغيل خادم محلي متوافق مع OpenAI API محصور تماماً على المضيف المحلي (127.0.0.1:8080) مع دعم البث الحي والتوثيق المحلي. localpilot gateway start --daemon --port 8080
localpilot keys | stats | connect إدارة مفاتيح API المحلية، وتتبع مقاييس استهلاك الرموز والأداء الحية (TPS، TTFT، الكمون)، وتوليد إعدادات الربط الموجهة للتطبيقات مثل OpenCode و Continue و Cursor. localpilot connect opencode --write
localpilot connections إدارة اتصالات أدوات التطوير وربطها بالنماذج، وإجراء فحص تشخيصي خماسي المراحل للاتصال، واستعادة الملفات بأمان عند قطع الاتصال دون المساس بتعديلات المستخدم. localpilot connections list
localpilot startup إدارة بدء التشغيل التلقائي لخادم الاستدلال على مستوى المستخدم فقط (systemd user أو launchd) دون الحاجة إطلاقاً لصلاحيات الجذر أو المسؤول (Root/Sudo). localpilot startup enable
localpilot hooks إدارة خطافات دورة الحياة المعزولة للأحداث (بدء الخادم، تحميل النماذج) مع عزل بيئة التشغيل، وقواطع الدوائر الآلية (Circuit Breakers) عند تكرار الفشل. localpilot hooks list
