User Protection

Our 5-Point Safety Guarantee

We engineered LocalPilot with non-technical users in mind so you never have to worry about your machine.

1

Zero RAM Freezes

LocalPilot inspects your exact hardware and enforces safe memory limits before downloading, preventing system freeze-ups.

2

Zero Telemetry & Tracking

No usage tracking, no remote logging, and no analytics. Your computer connects to the internet only when downloading the open model you chose.

3

No Root / Sudo Required

Installs cleanly inside your personal user folder. It never modifies operating system files or installs hidden background root services.

4

Respects Your Other Tools

Already have Ollama or LM Studio? LocalPilot connects politely, unloads memory when done, and never kills or corrupts other services.

5

1-Command Clean Removal

If you decide you no longer want LocalPilot, one command deletes every model, log, and configuration file. Nothing is left behind.

★

Free & Open Forever

Licensed under GNU GPLv3. Transparent source code, public releases, and zero hidden commercial tiers.
